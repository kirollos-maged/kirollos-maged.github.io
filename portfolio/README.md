# Kirollos Maged — Professional Portfolio

A modern, fully responsive single-page portfolio website built with pure HTML, CSS, and JavaScript.

## Features

- **Dark / Light theme** toggle (persisted in localStorage)
- **Typing animation** in the hero section
- **Smooth scrolling** navigation with active section highlighting
- **Mobile-responsive** hamburger menu
- **Scroll animations** (fade-in on intersect)
- **Interactive contact form** (UI simulation)
- **Back-to-top** button
- Clean cyber-security aesthetic with modern typography

## How to Use

1. Open `index.html` in any modern browser
2. Or serve locally:
   ```bash
   # Python
   python -m http.server 8000

   # Node
   npx serve .
   ```
3. Visit `http://localhost:8000`

## File Structure

```
portfolio/
├── index.html      # Main structure & content
├── styles.css      # All styling (CSS variables, responsive)
├── script.js       # Interactivity & animations
└── README.md
```

## Customization

- Update LinkedIn / GitHub links in `index.html`
- Replace project descriptions with real ones if available
- Connect the contact form to Formspree, EmailJS, or a backend
